✅ Request/Response Samples
1. Insert a new service

Request (JSON):

{
  "mode": "INSERT",
  "enquiry_id": "ENQ001",
  "amc_id": "AMC001",
  "client_name": "ABC Pvt Ltd",
  "contact_person_name": "John Doe",
  "contact_no1": "9876543210",
  "requirement_category": "AC Maintenance",
  "delivered_date": "2025-09-25",
  "service_status": "Open",
  "service_date": "2025-09-30",
  "created_by": "admin"
}


Response:

{
  "status": "success",
  "message": "Service inserted successfully",
  "id": 15
}
