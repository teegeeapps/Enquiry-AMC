Sample Requests & Responses (all modes)

Use Content-Type: application/json and send JSON body for all calls (POST).

1) insert — create assignment(s)

Request

{
  "mode": "insert",
  "enquiry_id": "ENQ001",
  "assignment_type": "ENQUIRY",
  "technicians": ["EMP001", "EMP002"],
  "delivery_instructions": "Call before visit",
  "customer_location": "Site A",
  "assigned_by": "admin",
  "visit_date": "2025-09-01",
  "technician_status": { "EMP001": 1, "EMP002": 0 }
}


Response

{
  "status": "success",
  "message": "Assignment created successfully"
}

2) update — update assignment(s) for same enquiry+type

Request

{
  "mode": "update",
  "enquiry_id": "ENQ001",
  "assignment_type": "ENQUIRY",
  "technicians": ["EMP002"],
  "delivery_instructions": "Updated note",
  "customer_location": "Site B",
  "assigned_by": "manager",
  "technician_status": { "EMP002": 0 }
}


Response

{
  "status": "success",
  "message": "Assignment updated successfully"
}
